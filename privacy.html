MailHub privacy policy

Last updated: October 5, 2026

Who uses MailHub

MailHub is a private application used only by its owner, Steve Keller, for his own mail accounts. It is not offered to the public and no one else can sign in to it.

What it does with Google data

With the owner's permission, MailHub uses the Gmail API to read, label, archive, move to trash and send messages in the owner's own Gmail account, and to save drafts there. It never permanently deletes mail.

Where the data goes

A copy of the owner's mail is stored on the owner's own computers so he can search and organize it. The data is not sold, not shared with anyone, and not used for advertising. It is processed only to provide these features to the owner.

MailHub's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.
